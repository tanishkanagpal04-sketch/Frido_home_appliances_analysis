# Frido_home_appliances_analysis

Frido Home Appliances – Data Analytics Project
📌 Project Overview
This project was developed as part of my Data Analyst Internship at Frido Home Appliances.
The project focuses on analyzing business data to identify meaningful patterns, trends, and insights across Sales, Production, and Inventory.
The analysis was performed using Python, Pandas, NumPy, Matplotlib, Seaborn, SQL, Excel, and Power BI.
